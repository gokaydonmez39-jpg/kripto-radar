# XRAY NASDAQ A10 — DeepEval shadow, no external LLM

**Provider:** https://github.com/confident-ai/deepeval, PyPI `deepeval==4.3.2` (2026-10-27), Apache-2.0; requires Python >=3.9,<4, checked in Python 3.12 isolated CI. This version's public PyPI package has no published provenance attestation; dependency-wide CVE/security clearance is not established.

**What actually runs:** Genuine DeepEval `BaseMetric` / `LLMTestCase` with **only synthetic** structured NASDAQ-style AL event data. Compares every field against a synthetic canonical record (symbol, asof, event ID, source, policy fingerprint, exact close/stop/target, device ACK false). Explicitly rejects wrong stop/target, fake iPhone delivery, altered source or ticker, duplicate keys, nonfinite price, malformed JSON, event identity mismatches. Sync and async metric parity; optimized Python tests. No default built-in LLM-as-judge metric or real ChatGPT messages are evaluated.

**Risks/limitations:** DeepEval may load `.env` files at import: opt out with `DEEPEVAL_DISABLE_DOTENV=1`. Framework has optional platform reporting, so CI has multiple telemetry-disable flags and NO user secrets; that is **not a firewall-level egress audit**. The actual premium notification format is free-text, not JSON; these tests only protect a hypothetical structured intermediate representation. DeepEval can be more expensive than the current 6-case Promptfoo checks, has many transitive Python dependencies, and offers **no alpha gain**. Additional model judge requires explicit privacy and cost authorization, plus a false-positive/negative benchmark, which is NOT granted here.

**Acceptance:** Green CI + Python -O + documented dependency graph + security scan + incremental cost/performance usefulness compared with existing Promptfoo, production diff guard, no production AL/Sheets/notify modifications. Until verified, **DRAFT / HOLD**. Never merge just because 11 synthetic cases pass. No iPhone delivery claim, no private customer data and no trading endpoint.
