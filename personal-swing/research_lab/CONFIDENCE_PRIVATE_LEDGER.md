# Confidence private ledger readiness

This new pure adapter checks the actual candidate and alert sheet schemas,
episode identity, XNAS session counts, fixed bracket, matching terminal event
and independently supplied original source-run witness IDs. It never
automatically repairs missing events or infers an old delivery receipt.
An event URL alone is not authenticated evidence. Even a matching verified
run ID is only a linkage candidate, not a raw-path or label witness.

No closed-only win rate, probability calibration, R return or model fit is
produced. Open, missing/unverified evidence, ambiguous dual-touch and
corporate terminal outcomes remain explicit HOLD/censor categories.
A future real evaluation requires the independently authenticated raw
post-origin path, PIT features/probability frozen at origin, explicit
cost model, and pre-registered OOS folds. No history replay/backfill or
production writes. Never log returned private episode identities publicly.
